# 🎰 Lottery Telegram Bot

Multiplayer-лотерея в Telegram с прозрачной системой билетов, лайв-обновлением и базовой экономикой. In-memory хранилище, без БД.

## Установка

```bash
npm install
```

## Настройка

1. Создайте бота через [@BotFather](https://t.me/BotFather) и получите токен.
2. Создайте файл `.env` в корне проекта:

```
BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz
```

## Запуск

```bash
npm start
```

## Структура проекта

| Файл | Описание |
|---|---|
| `bot.js` | Точка входа, обработчики Telegram |
| `gameManager.js` | Комнаты, игровой цикл, розыгрыш |
| `userManager.js` | Баланс, бонусы, рефералы |
| `economyManager.js` | Депозиты, вывод средств |

## Главное меню

```
🎮 Играть       — выбрать комнату и купить билеты
💰 Баланс       — баланс, статистика
🎁 Бонус        — ежедневный бонус +$1
👥 Рефералы     — реферальная ссылка, статистика
📥 Пополнить    — адрес для депозита
📤 Вывести      — заявка на вывод
```

## Комнаты

| Комната | Ставка | Игроков | Билеты |
|---------|--------|---------|--------|
| 🟢 | $1 | 2–5 | 1–10 |
| 🔵 | $5 | 2–5 | 1–10 |
| 🔴 | $10 | 2–5 | 1–10 |

## Ход игры

1. Игрок выбирает комнату → выбирает кол-во билетов (1–10) через inline-клавиатуру → списывается ставка.
2. Каждый билет: 5 уникальных чисел (1–30).
3. Ожидание заполнения (мин. 2, макс. 5). При достижении минимума — 15 сек на подключение остальных.
4. **Полная прозрачность**: бот показывает ВСЕ билеты ВСЕХ игроков перед стартом.
5. 🔒 Билеты фиксируются — нельзя менять или добавлять игроков.
6. Каждые 2 секунды выпадает уникальное число (1–30).
7. **Лайв-обновление**: каждое число в билете отображается как ✅ (выпало) или ❌ (нет).
8. Первый игрок, у которого все 5 чисел совпали — побеждает.
9. Выигрыш = банк - 5% комиссии.

## Лайв-формат

```
🔢 Выпало: 19, 9, 6, 22

👤 @user1 (ты):
🎟 7❌ 8❌ 19✅ 22✅ 27❌ → 🔶 2/5

👤 @user2:
🎟 3❌ 10❌ 14❌ 19✅ 27❌ → 🔶 1/5
```

## Реферальная система

- `/start ref_<userId>` — регистрация по ссылке
- Реферер получает 2% от ставок реферала
- Статистика и ссылка в меню «👥 Рефералы»

## Крипто (MVP)

- **Пополнение**: показывается mock-адрес кошелька
- **Вывод**: пользователь вводит адрес и сумму → создаётся заявка со статусом `pending`

## Примечания

- Стартовый баланс: **$10**.
- Бонус: **+$1 раз в день**.
- Комиссия: **5%** от банка.
- Реферальное вознаграждение: **2%** от ставок реферала.
- Данные хранятся только в памяти — при перезапуске бота всё сбрасывается.
