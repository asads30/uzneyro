# Telegram Tables Bot (MVP)

Игровой Telegram-бот со столами (публичные и приватные), рефералами и базовой экономикой.

Стек:
- Node.js
- telegraf
- in-memory storage (Map)

## Установка

```bash
npm install
```

## Настройка

1. Создай бота через @BotFather.
2. В корне проекта создай файл .env:

```env
BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz
```

## Запуск

```bash
npm start
```

## Структура

| Файл | Назначение |
|---|---|
| bot.js | Точка входа, команды и callback-сценарии |
| gameManager.js | Столы, вход игроков, авто/ручной старт, игровой цикл |
| userManager.js | Профили, баланс, бонусы, рефералы |
| economyManager.js | MVP-депозиты и вывод |

## Главное меню

```text
🎮 Создать стол    📋 Публичные столы
💰 Баланс          🎁 Бонус
👥 Рефералы        📥 Пополнить
📤 Вывести
```

## Игровые столы

Создание стола идет по шагам:
1. Ставка: $1, $3, $5, $10, $15, $20
2. Количество игроков: 2..6
3. Тип: публичный или приватный
4. Количество билетов создателя: 1..3

Модель стола:

```json
{
	"id": "ABC123",
	"creatorId": 123,
	"bet": 5,
	"maxPlayers": 4,
	"players": [],
	"isPrivate": false,
	"status": "waiting"
}
```

Особенности:
- Один пользователь может быть только в одном столе.
- В полный стол войти нельзя.
- Параметры стола после создания не меняются.
- Приватный стол доступен только по ссылке вида:
	https://t.me/<bot_username>?start=table_<TOKEN>
- Публичные столы видны в списке "📋 Публичные столы".

## Старт игры

Поддерживаются оба режима:
- Автостарт при заполнении стола (players.length === maxPlayers)
- Ручной старт кнопкой "🚀 Начать игру" (только создатель, минимум 2 игрока)

Перед стартом показываются все игроки и все билеты, затем билеты фиксируются.

## Игровая логика

- У каждого игрока 1..3 билета.
- Каждый билет: 5 уникальных чисел 1..30.
- Каждые 2 секунды выпадает число без повторов.
- Обновление идет live, по всем игрокам.
- Побеждает первый игрок, у которого полностью совпал любой билет.

Выплата:
- Банк = сумма ставок всех игроков
- Комиссия = 5%
- Приз = банк - комиссия

## Рефералы

- Поддержка start-параметра: /start ref_<userId>
- У пользователя есть referralCode (равен его userId) и referredBy.
- При каждом успешном депозите реферала реферер получает фиксировано $0.05.
- Для одного события депозита реферальное начисление не дублируется.

Экран "👥 Рефералы":
- Количество приглашенных
- Суммарный заработок
- Персональная ссылка

## Депозит (MVP)

Сценарий:
1. Нажать "📥 Пополнить"
2. Бот покажет адрес
3. Нажать "✅ Я оплатил"
4. Ввести сумму
5. Баланс обновится мгновенно (симуляция)

## Пример сценария

1. User A создает приватный стол: ставка $5, 4 игрока, 2 билета.
2. Бот выдает ссылку приглашения.
3. User B открывает ссылку /start table_TOKEN и входит в стол.
4. Создатель жмет "🚀 Начать игру".
5. Каждые 2 секунды выпадают уникальные числа, идет live-обновление билетов.
6. User B закрывает билет первым и получает выплату из банка за вычетом 5%.
7. User B делает депозит через "📥 Пополнить".
8. Если User B был приглашен по ref-ссылке, реферер получает +$0.05.

## Ограничения MVP

- Данные в памяти процесса (без БД).
- После перезапуска все данные сбрасываются.
